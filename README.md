# Tiny Einstein — Curriculum Calendar

[Open the calendar](https://lysakanatoliia-png.github.io/te-curriculum-calendar/)

A static teacher-workspace prototype with a September 2026 calendar, weekly themes, school tours, enrichment, special events, sample birthdays, annual curriculum view, and an exemplar daily teaching packet with printable PDFs.

## Development

Edit the HTML, CSS, JavaScript and calendar data here. Run `node checks.cjs` before pushing. Updates pushed to `main` are published by GitHub Pages from the repository root.

- `index.html`, `app.js`, `styles.css`: calendar and teacher workspace.
- `demo-calendar-data.js`: illustrative calendar events and fictional birthday records.
- `curriculum-data.js`: curriculum themes; unused internal Drive resource URLs are omitted from the public copy.
- `exemplar-day.*`, `exemplar-data.js`: detailed sample day, opened from September 15.
- `print/`: teacher guide and child materials.
- `assets/`: local brand assets and fonts.

## Current scope

This is the newer transferred portal snapshot with populated events and the detailed sample day, published September 28, 2026. Later academic Daily Guide image concepts have not yet been implemented in the portal.

Calendar dates, bookings, birthdays, lesson scenarios and approval states are demonstrations. Approval changes reset on reload; there is no shared database, real account access, or administrator messaging. Teacher-guide visual redesign and pedagogical review remain pending.
